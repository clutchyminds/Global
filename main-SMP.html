Infos sur les plugins du serveur

KAYOU SMP utilise plusieurs plugins pour rendre le serveur plus fun et pratique : un plugin de camouflage en PvP, un plugin de commandes utiles (homes, tpa, etc.) et un plugin de crafts personnalisés.

EssentialsX : commandes utiles

EssentialsX ajoute les commandes de base pour un serveur survie : /home, /sethome, /spawn, /tpa, etc., pour faciliter les déplacements et la gestion de tes bases.

CustomCrafting : crafts personnalisés

CustomCrafting permet d'ajouter des recettes de craft personnalisées pour la table de craft, le four, le fumoir, la forge et plus encore, avec une interface en jeu (/cc). [web:51]

EssentialsX
Commandes pour le confort de jeu

EssentialsX ajoute toutes les commandes pratiques pour ton quotidien : /home, /sethome, /delhome pour gérer tes bases, /spawn pour revenir au point de départ, /tpa pour rejoindre tes amis.

Sur KAYOU SMP, tout le monde a accès aux commandes utiles, ce qui permet de se déplacer facilement sans casser la survie ni le côté fair-play entre joueurs.

CustomCrafting
Crafts et items personnalisés

CustomCrafting permet au staff de créer des recettes sur mesure directement en jeu : craft de nouveaux items, recettes avancées, conditions spéciales, etc. [web:51]

Sur KAYOU SMP, certains items spéciaux se débloquent via des crafts personnalisés pour récompenser l'exploration et les projets des joueurs, sans rendre le serveur trop facile.
