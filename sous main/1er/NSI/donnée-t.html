📚 Cours complet – Types construits en NSI

Les types construits permettent de regrouper plusieurs valeurs (de base ou non) dans la même variable : l’ordinateur les stocke et les manipule selon des règles précises.

Type construit Exemple Présentation Opérations courantes
Liste [3, 6, 9] Suite d’éléments modifiable, ordonnée.
Les éléments peuvent être de tout type !		 Ajout (append()), accès par index, suppression
Tableau [[1,2],[3,4]] Grille ou matrice (souvent à 2 dimensions).
Comme une feuille Excel !		 Parcours ligne/colonne, accès rapide, efficace en calcul
Tuple (7, "Bordeaux") Suite de valeurs non modifiables (immuables), ordonnées. Indexation, stockage de coordonnées, retour multiple par fonction
Ensemble {1, 2, 3} Groupe non ordonné, pas de doublons. Test d’appartenance (in), union, intersection
Dictionnaire {'nom':'Jean', 'age':17} Clés → valeurs.
Accès direct à chaque info (comme un annuaire)		 Ajout/modif via clé, recherche rapide

Pourquoi les utiliser ?
- Organiser l’info : garder une collection, une table, associer noms/valeurs...
- Gagner en efficacité : traiter 1000 valeurs en une seule variable !
- Faire des traitements plus évolués : recherche, tris, parcours de données, etc.

  • En mémoire : chaque élément est numéroté (index), ou associé à une clé (dico), les éléments sont rangés “à la suite”.
  • Syntaxe Python : liste = [5, 7, 6]
    matrice = [[1,2],[3,4]]
    t = (x, y)
    s = {'A', 'B'}
    d = {"clé":valeur}
  • Pour accéder à un élément : liste[1] — pour les dictionnaires : d["clé"]

Utilisé partout : listes de courses, tableaux Excel, grille de jeu, stats de joueur, messages, configurations...

📋 Fiche synthèse interactive

  • Comment accéder au 3e élément d’une liste ? Utilise l’indice 2, car on commence à compter à 0 ! ma_liste[2]
  • Quelle différence entre liste et tuple ? La liste est modifiable (“mutable”), le tuple non !
  • Ce que stocke un dictionnaire ? Des couples “clé : valeur”. Ex. : noms et numéros, mots et traductions.
  • Défi : Un ensemble peut-il contenir 2 fois la même valeur ? Non, pas de doublon dans un set.
  • Astuce : Comment trier une liste ? Avec ma_liste.sort() ou sorted(ma_liste).

🌍 Applications concrètes

  • Listes de courses, gestion d’une classe (noms), notes d’élèves (tableau), scores de jeux (dictionnaire), “amis Facebook” (ensemble)…
  • Manipuler et chercher rapidement dans ses données (liste de contacts téléphone, recherche dans une base, etc.)
  • Stockage de données réelles : tableaux d’images ou tables (Excel…)

❌ Erreurs fréquentes à éviter

  • Compter à partir de 1 : l’ordinateur commence à 0 !
  • Confondre liste et ensemble (liste = ordonnée, ensemble = non ordonné et pas de doublon)
  • Chercher un élément par index dans un dictionnaire (on utilise une clé)
  • Penser que tout ce qui ressemble à une liste permet la modification (faux pour tuple)
  • Oublier la syntaxe des crochets [] (liste), accolades {} (ensemble, dico), parenthèses () (tuple)

📚 Lexique express

Liste : suite ordonnée d’éléments, modifiable
Tableau : structure à 2 dimensions (matrice)
Tuple : suite ordonnée et non modifiable
Ensemble : collection sans doublon et non ordonnée
Dictionnaire : ensemble de couples “clé : valeur”

📖 Anecdotes et histoire

  • En Python, une “liste” correspond à un “tableau dynamique” en C++ ou Java !
  • Le type “dictionnaire” s’appelle “hashmap” ou “map” dans d’autres langages.
  • Un tuple peut servir à retourner plusieurs valeurs en une seule ligne dans une fonction Python !
  • La recherche dans un ensemble (“set”) est souvent plus rapide que dans une liste pour les gros volumes de données.

Astuces mémoire : Les crochets “[]” dessinent bien une “listE” (E de Éléments) ! Un tuple = “tunique” (une seule fois, non modifiable), un dico = “données indexées par Clé-Objet” !

💡 Méthodologie pour réussir ton contrôle

  • Trouve le type construit adapté au problème : liste pour une suite, tuple pour des coordonnées, dico pour un répertoire, tableau pour une grille…
  • Maîtrise la syntaxe : crochets, parenthèses ou accolades
  • Sache parcourir, modifier, trier ou rechercher dans la structure – écris un exemple
  • Justifie pourquoi ce type résout bien le problème posé
  • Méfie-toi des indexations (on commence à zéro), et des types non mutables (tuple) !
