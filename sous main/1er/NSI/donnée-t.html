📚 Cours complet – Types construits

Les types construits regroupent plusieurs valeurs dans une seule variable, ce qui permet de structurer les données et de les manipuler efficacement.

Type construit Exemple Présentation Opérations courantes
Liste [3, 6, 9] Suite ordonnée, modifiable, pouvant contenir tout type d’objets. append(), remove(), indexation, parcours.
Tableau [[1,2],[3,4]] Matrice 2D (comme un mini tableur). Accès par ligne/colonne, double boucle, calculs.
Tuple (7, "Bordeaux") Suite ordonnée non modifiable (immuable). Indexation, retour multiple de fonctions.
Ensemble {1, 2, 3} Collection non ordonnée sans doublons. in, union, intersection, différence.
Dictionnaire {'nom':'Jean','age':17} Paires clé → valeur (comme un annuaire). Accès par clé, ajout/suppression, parcours items().

Syntaxe Python :
de> liste = [5, 7, 6]
matrice = [[1,2],[3,4]]
t = (x, y)
s = {'A', 'B'}
d = {"clé": valeur}

📋 Fiche synthèse interactive

  • 3ᵉ élément d’une liste ? Index 2 (on commence à 0) : de>ma_liste[2].
  • Liste vs tuple ? Liste mutable, tuple immuable.
  • Que stocke un dictionnaire ? Des couples clé : valeur, par exemple nom → numéro.
  • Un ensemble accepte-t-il les doublons ? Non : tout doublon est supprimé automatiquement.
  • Trier une liste ? de>ma_liste.sort() (en place) ou de>sorted(ma_liste) (nouvelle liste).

🌍 Applications concrètes

  • Listes de courses, collections d’objets, notes d’élèves.
  • Dictionnaire pour contacts, configs, traductions.
  • Tableaux pour images, grilles de jeux, données scientifiques.

❌ Erreurs fréquentes

  • Indexer à partir de 1 au lieu de 0.
  • Confondre liste (ordonnée) et ensemble (non ordonné, sans doublon).
  • Indexer un dictionnaire avec un entier plutôt qu’une clé.
  • Essayer de modifier un tuple (impossible).
  • Oublier la syntaxe : [] pour liste, {} pour set/dict, () pour tuple.

📚 Lexique express

Liste : suite ordonnée modifiable.
Tableau : matrice 2D de valeurs.
Tuple : suite ordonnée immuable.
Ensemble : collection sans doublon, non ordonnée.
Dictionnaire : couples clé : valeur.
Astuces mémoire : crochets → lisTE ; tuple = “tunique” (pas modifié après coup) ; dico = dictionnaire de téléphone (clé = nom, valeur = numéro).
