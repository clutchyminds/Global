Masterclass JavaScript — Cours ultra complet & interactif

Découvre JavaScript : variables, fonctions, objets, DOM, événements, asynchrone, ES6+ et projets.

💡 Qu’est-ce que JavaScript ?

  • Langage de programmation exécuté dans le navigateur (et aussi côté serveur avec Node.js).
  • Permet de rendre une page dynamique : mises à jour de contenu, animations, validations, appels réseau.
  • Complète HTML (structure) et CSS (style) pour former le “trio du web”.

🔤 Variables, types et valeurs

Déclarations :

  • de>let : variable modifiable.
  • de>const : constante (référence non réaffectée).
  • de>var : ancien mot‑clé, à éviter en général.

Types de base : de>number, de>string, de>boolean, de>null, de>undefined, de>object.

de>let age = 25;
const nom = "Alice";
var estActif = true;
let montant = 15.75;
JavaScript est dynamiquement typé : le type peut changer, ce qui impose de bien comprendre les conversions implicites.

⚖️ Opérateurs et expressions

  • Arithmétiques : de>+, de>-, de>*, de>/, de>%, de>**.
  • Comparaison : de>==, de>===, de>!=, de>!==, de><, de>>, etc.
  • Logiques : de>&&, de>||, de>!.
de>let x = 10 + 5;
let estEgal = (x === 15);
let estVrai = (true && false); // false

🔀 Conditions et boucles

  • de>if / else if / else pour les choix.
  • de>for, de>while, de>do...while, de>for...of pour les répétitions.
de>if (age >= 18) {
  console.log("Majeur");
} else if (age >= 13) {
  console.log("Adolescent");
} else {
  console.log("Enfant");
}

for (let i = 0; i < 5; i++) {
  console.log(i);
}

🧩 Fonctions

de>function saluer(nom) {
  return "Bonjour " + nom + " !";
}

console.log(saluer("Alice"));
de>const saluer = nom => `Bonjour ${nom} !`;
console.log(saluer("Bob"));

📦 Objets et tableaux

de>const personne = {
  nom: "Alice",
  age: 30,
  actif: true
};

const fruits = ["pomme", "banane", "orange"];

console.log(personne.nom); // Alice
console.log(fruits[1]);    // banane

🖥️ DOM et manipulation de page

de>const titre = document.querySelector("h1");
titre.textContent = "Titre modifié par JS";

const div = document.createElement("div");
div.textContent = "Nouveau contenu";
document.body.appendChild(div);

🖱️ Événements

de>const bouton = document.querySelector("button");
bouton.addEventListener("click", () => {
  alert("Bouton cliqué !");
});

⏳ Asynchrone, Promesses et async/await

de>async function fetchData() {
  try {
    const response = await fetch("https://api.example.com/data");
    const data = await response.json();
    console.log(data);
  } catch (error) {
    console.error("Erreur :", error);
  }
}
fetchData();

💡 Quiz interactif

  • Quelle déclaration empêche la réaffectation ? de>const
  • Comment écouter un clic ? de>element.addEventListener('click', handler)
  • Créer un élément HTML ? de>document.createElement()

💡 Exercices pratiques

1. Changer le texte d’un de><h1> au clic d’un bouton.

2. Coder une fonction qui renvoie le max d’un tableau.

de>const bouton = document.querySelector("button");
const titre = document.querySelector("h1");

bouton.addEventListener("click", () => {
  titre.textContent = "Titre changé !";
});

function maxTableau(arr) {
  return Math.max(...arr);
}

console.log(maxTableau([10, 5, 30, 25]));

🧠 Méthodologie & bonnes pratiques

  • Tester dans la console du navigateur.
  • Privilégier de>let/de>const à de>var.
  • Découper en fonctions claires et réutilisables.
  • Utiliser les devtools (console, debugger, réseau).
  • Toujours gérer les erreurs, surtout en asynchrone.
