💡 Qu’est-ce que JavaScript ?

  • JavaScript est un langage de programmation interprété principalement côté client, intégré dans tous les navigateurs modernes.
  • Il permet de rendre une page web dynamique et interactive, par exemple en modifiant le contenu, en réagissant aux actions utilisateur ou en communiquant avec un serveur.
  • JavaScript est aujourd’hui aussi utilisé côté serveur (Node.js), dans les applications mobiles, le développement de jeux, etc.
  • Il est souvent utilisé conjointement avec HTML pour la structure et CSS pour le style, formant les bases du web moderne.

🔤 Variables, types et valeurs en JavaScript

JavaScript gère plusieurs types de données différents, stockés dans des variables déclarées avec let, const ou var.

  • let : variable mutable (modifiable), préférée actuellement.
  • const : constante, variable non modifiable après assignation.
  • var : ancienne déclaration, à éviter car moins stricte.

Types de base :

  • number (entiers et décimaux),
  • string (texte),
  • boolean (true/false),
  • null (valeur vide volontaire),
  • undefined (valeur non définie),
  • object (collections d’éléments).
let age = 25;
const nom = "Alice";
var estActif = true;
let montant = 15.75;

À la différence de Python, JavaScript est faiblement typé : tu peux changer le type d’une variable à tout moment. Cela demande de faire attention aux conversions implicites.

⚖️ Opérateurs et expressions

Les opérateurs servent à faire des calculs ou comparaisons.

  • Opérateurs arithmétiques : +, -, *, /, %, ** (puissance).
  • Opérateurs de comparaison : ==, ===, !=, !==, <, >, <=, >=.
  • Opérateurs logiques : && (et), || (ou), ! (non).
let x = 10 + 5;
let estEgal = (x === 15);
let estVrai = (true && false); // retourne false

🔀 Structures de contrôle : conditions et boucles

Le contrôle du flux permet d'exécuter des instructions selon des conditions ou en boucle.

  • if / else if / else : exécute un bloc selon qu'une condition est vraie ou non.
  • switch : alternative élégante à plusieurs conditions if.
  • while : boucle tant qu’une condition est vraie.
  • do...while : boucle au moins une fois avant de tester la condition.
  • for : boucle avec compteur d’itérations précis.
  • for...in / for...of : boucles spécialisées pour objets et collections.
if (age >= 18) {
  console.log("Majeur");
} else if (age >= 13) {
  console.log("Adolescent");
} else {
  console.log("Enfant");
}

for (let i = 0; i < 5; i++) {
  console.log(i);
}

🧩 Fonctions : blocs réutilisables de code

Une fonction prend des entrées (paramètres), fait des actions et peut retourner une sortie.

Déclaration classique :

function saluer(nom) {
  return "Bonjour " + nom + " !";
}

console.log(saluer("Alice"));

Fonctions fléchées (syntax plus courte, souvent pour les fonctions anonymes) :

const saluer = nom => `Bonjour ${nom} !`;
console.log(saluer("Bob"));

📦 Objets et tableaux

En JavaScript, les objets et tableaux sont les structures de données principales.

  • Objet : collection clé-valeur — comme un dictionnaire Python.
  • Tableau : liste ordonnée d'éléments.
const personne = {
  nom: "Alice",
  age: 30,
  actif: true
};

const fruits = ["pomme", "banane", "orange"];

console.log(personne.nom); // Alice
console.log(fruits[1]);    // banane

🖥️ Manipulation du DOM (Document Object Model)

Le DOM est une représentation en mémoire de la page HTML chargée. JavaScript peut lire, changer ou ajouter des éléments via le DOM.

  • Sélectionner un élément avec document.querySelector() ou document.getElementById().
  • Changer le contenu ou l’attribut avec textContent, innerHTML, setAttribute.
  • Créer des éléments avec document.createElement() puis insérer dans le DOM avec appendChild().
const titre = document.querySelector("h1");
titre.textContent = "Titre modifié par JS";

const div = document.createElement("div");
div.textContent = "Nouveau contenu";
document.body.appendChild(div);

🖱️ Événements et gestionnaires

JavaScript permet d’écouter les actions utilisateurs (clics, survols, touches clavier) via les événements et déclenche des fonctions en réponse.

const bouton = document.querySelector("button");
bouton.addEventListener("click", () => {
  alert("Bouton cliqué !");
});

Les événements courants : click, mouseover, keydown, submit (formulaires), etc.

⏳ Programmation Asynchrone : Promesses, Async/Await

JavaScript est mono-thread, mais gère l’asynchronicité pour exécuter des tâches longues sans bloquer.

  • Callbacks : fonctions passées en argument, appelées après une tâche asynchrone.
  • Promesses : objets représentant un résultat futur, avec then et catch.
  • Async/await : syntaxe moderne rendant le code asynchrone plus lisible.
async function fetchData() {
  try {
    const response = await fetch("https://api.example.com/data");
    const data = await response.json();
    console.log(data);
  } catch (error) {
    console.error("Erreur :", error);
  }
}
fetchData();

💡 Exercices pratiques

1. Crée un script qui modifie le texte d’un titre <h1> au clic d’un bouton.

2. Implémente une fonction qui prend un tableau et retourne le maximum.

const bouton = document.querySelector("button");
const titre = document.querySelector("h1");

bouton.addEventListener("click", () => {
  titre.textContent = "Titre changé !";
});

function maxTableau(arr) {
  return Math.max(...arr);
}

console.log(maxTableau([10, 5, 30, 25]));

🧠 Méthodologie & bonnes pratiques

  • Teste ton code souvent dans la console du navigateur.
  • Commente ton code pour expliquer les parties complexes.
  • Privilégie let et const plutôt que var pour éviter les problèmes de portée.
  • Utilise les outils de développement intégrés (console, débogueur).
  • Découpe ton code en fonctions réutilisables et claires.
  • Toujours gérer les erreurs, surtout en asynchrone.
