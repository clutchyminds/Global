Masterclass CSS — La version super détaillée & interactive

Toutes les bases expliquées : boîtes, couleur, responsive, animations, et plein de petits hacks pour maîtriser le style web.

À quoi sert le CSS ? Grand résumé

  • CSS (Cascading Style Sheets) indique au navigateur comment afficher chaque élément HTML : couleurs, tailles, marges, polices, animations, effets au survol.
  • Sans CSS, les pages seraient du texte brut noir sur fond blanc, sans mise en page moderne.
  • Le CSS s’applique toujours à des balises HTML via des sélecteurs.
  • La “cascade” signifie que les règles les plus précises ou les plus récentes l’emportent.
Où écrire du CSS ?
– Dans un bloc de><style> dans le <head> du HTML.
– Dans un fichier .css séparé importé avec de><link rel="stylesheet" href="style.css">.
– Directement dans une balise avec l’attribut de>style="..." (à éviter pour un gros projet).

🧩 Structure et box-model CSS

Un “rule-set” CSS : de> h1 {
 color:#f5a623;
 font-size:2rem;
}
Box-model : chaque élément est une boîte avec :
  • Contenu (texte, image).
  • padding : marge intérieure.
  • border : bordure.
  • margin : espace extérieur par rapport aux autres éléments.

👀 Couleurs & unités

  • Couleurs : de>color (texte), de>background-color (fond), de>border-color (bordure).
  • Noms (red, deepskyblue), hexadécimal (#e06359), de>rgb() et de>rgba() pour gérer la transparence.
  • Unités : px, em, rem, %, vw/vh (viewport).
  • Police : de>font-family: Arial, sans-serif;, de>font-weight:bold;, de>font-size:2rem;.

📐 Position, display & responsive

  • display : block, inline, inline-block, flex, grid.
  • position : static, relative, absolute, fixed, sticky.
  • Responsive : media queries comme de>@media (max-width:800px){ ... }.
  • Centrer horizontalement un bloc : largeur fixe + de>margin-left:auto; margin-right:auto; ou flexbox.

💡 Quiz & petites astuces

  • Mise d’ombre sur une boîte ? de>box-shadow:5px 5px 12px #0003;
  • Curseur “main” sur un bouton ? de>cursor:pointer;
  • Texte qui pulse ? de> @keyframes pulse{0%{transform:scale(1);}50%{transform:scale(1.1);}100%{transform:scale(1);}}
    .pulse{animation:pulse 1s infinite;}
  • Astuce responsive de>@media(max-width:600px){body{font-size:1em;background:#faf;}}
  • Rendre une image ronde de>img{border-radius:50%;} + largeur = hauteur.
  • Réduire une image au survol de>img:hover{transform:scale(0.9);transition:transform 0.2s;}

🌍 Idées projets CSS

  • Refaire une page YouTube/Twitter avec tes propres couleurs.
  • CV graphique, portfolio responsive, landing page.
  • Mini jeux HTML/CSS/JS (quiz, memory, pixel art).
  • Dark mode automatique via variables CSS + media queries.

❌ Erreurs fréquentes

  • Oublier le de>; ou utiliser de>= au lieu de de>:.
  • Utiliser un id dans le CSS sans l’avoir mis dans le HTML.
  • Abuser de de>position:absolute, ce qui casse le responsive.
  • Empiler margins/paddings sans comprendre le box-model.

📚 Lexique enrichi CSS

Rule-set : sélecteur + bloc de déclarations.
Box model : contenu + padding + border + margin.
Opacity : niveau de transparence.
Media query : règle CSS conditionnelle selon l’écran.
Flexbox / Grid : systèmes modernes de mise en page.
Pseudo-classes : de>:hover, de>:focus, de>:active.
Anecdote & astuces pro : CSS a été créé pour séparer structure (HTML) et style dès les années 90. Les bons projets utilisent des petites classes réutilisables (de>.btn, de>.card, de>.tag) plutôt qu’un gros fouillis.

💡 Méthodologie & réflexes CSS

  • Lire le HTML pour savoir quoi cibler (balise, classe, id).
  • Garder une palette de couleurs cohérente.
  • Tester sur mobile avec des media queries.
  • Commenter les fichiers CSS dès que le projet grossit.
  • Commencer simple, puis ajouter graduellement animations et effets.
  • Se créer une “boîte à outils” de classes réutilisables.
