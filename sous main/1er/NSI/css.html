Masterclass CSS — La version super détaillée & interactive

Toutes les bases expliquées : boîtes, couleur, responsive, animations, rigole ET maîtrise les styles web comme un pro !

À quoi sert le CSS ? Grand résumé

  • CSS (“Cascading Style Sheets”) indique au navigateur comment afficher chaque élément HTML : couleur, taille, marges, contours, polices, animations, effets au survol…
  • Sans CSS, tous les sites ressembleraient à Wikipédia sans styles (texte noir sur blanc, pas de boutons jolis, ni d’alignements ni de couleurs !)
  • Le CSS s’applique toujours aux balises HTML.
  • Il est “cascadant” : les styles les plus précis ou placés “après” l’emportent.
Où écrire du CSS ?
– Ensemble <style> dans le <head> du HTML
– Dans un fichier .css séparé et importé avec <link rel="stylesheet" href="mystyle.css">
– Directement sur une balise : <h1 style="color:red;">Coucou</h1>

🧩 Comment ça marche ? — Structure et boîte CSS

1 sélecteur = 1 ensemble de règles : h1 {
  color: #f5a623;
  font-size: 2rem;
}
Tout élément HTML est “dans une boîte” CSS (box-model) :
  • Contenu (texte/image…)
  • Padding : marge intérieure
  • Border : contour coloré, épais ou non
  • Margin : espace entre la boîte et les autres éléments

👀 De la couleur partout ! + Les unités de taille

  • Pour COLORER : color: blue; (texte) odede>background-color: yellow; (fond) odede>border-color: #e06359; (bordure)
  • Tu peux utiliser : - nom de couleur anglais (red, yellowgreen…) - code hexadécimal (#e06359) - rgb(20,150,111) ou rgba(255,0,0,0.5) pour la transparence !
  • UNITÉS : - px (pixels, absolut) - odede>em (relatif à la police de l’élément), - rem (relatif à la racine du doc), - odede>% (pourcent), - odede>vw (viewport, largeur écran)
  • Changer la police : font-family: Arial, sans-serif; Tout mettre en gras : font-weight:bold; Texte plus grand : font-size: 2rem;

📐 Position, display, responsive : faire un site actuel

  • Display : - block (occupe toute la largeur : div, p…) - inline (prend que la place du texte, ex : a, span…) - flex (pour aligner horizontal, vertical, centrer facilement)
  • Positionnement : - position: static (par défaut) - odede>relative (décalage selon sa position) - odede>absolute (par rapport au conteneur parent) - fixed (reste visible pendant le scroll) - sticky (se “colle” en haut en scrollant)
  • Responsive ? Grâce aux media queries : @media (max-width:800px) { h1 { font-size:1.4em; } }
  • Centre tout : margin:auto + display:flex; justify-content:center;

💡 Quiz, trucs et astuces : base, avancé, fun !

  • Comment mettre une ombre sur une boîte ? box-shadow: 5px 5px 12px #2225;
  • Changer la couleur du curseur ? cursor: pointer; sur un bouton/élément interactif
  • Faire un texte qui “pulse” ? @keyframes pulse {
     0% { transform:scale(1); }
     50% { transform:scale(1.1);}
     100%{ transform:scale(1); }
    }
    .pulse { animation: pulse 1s infinite; }
  • Astuce responsive : @media (max-width:600px){body {font-size:1em;background:#faf;}}
  • Deux façons de faire un bouton rond : border-radius: 50%; ET largeur = hauteur !
    clip-path: circle(50%);
  • Réduire la taille d’une image au survol ? img:hover { transform:scale(0.9); }

❌ Erreurs courantes expliquées

  • Oublier ; à la fin d’une propriété, ou “:” entre propriété et valeur
  • Écrire = au lieu de : (mauvaise syntaxe !)
  • Mettre #unique { } alors que l’élément n’a pas d’id="unique"
  • Utiliser absolute partout, ce qui casse l’alignement responsive
  • Accumuler margin+padding+width sans contrôler le box-model, ça déborde…
  • Oublier de tester sur mobile, d’inclure l’UTF-8 dans le HTML (charset correct)

📚 Lexique enrichi CSS

Rule-set : ensemble sélecteur + accolades + propriété/valeur
Box Model : structure “contenu + padding + border + margin”
Opacity : transparence
media query : règle CSS seulement pour certains écrans
@import : permet d’inclure un autre fichier CSS
Flexbox / Grid : systèmes modernes de mise en page
:hover, :focus, :active : pseudo-classes pour intéragir avec l’utilisateur
Anecdote & Astuces Pro : Le CSS a été inventé pour séparer la structure (HTML) du style (CSS) dès 1996 ! Les meilleurs sites web font du CSS “modulaire” : plein de petites classes intelligentes pour (presque) tout réutiliser.
**Détail fun** : background: repeating-linear-gradient te permet même de créer des fonds “carreaux de cahier” pour réviser !

💡 Méthodologie & réflexes CSS

  • Lire le code HTML pour savoir quoi cibler (balise ? id ? classe ?...)
  • Utiliser un seul système de couleurs pour garder une harmonie
  • Toujours tester son site sur mobile (odede>@media), sur plusieurs navigateurs
  • Commenter (“/* ... */”) ses fichiers CSS quand projet > 1 page
  • Commencer simple, puis ajouter les effets “wow” (ombre, transition, grid, responsive)
  • Se faire une collection de “petites classes CSS” réutilisables (.btn, .card)
