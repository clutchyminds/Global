📚 Cours complet – Fonctionnement interne

Un ordinateur associe matériel (hardware) et logiciels (software), coordonnés par un système d’exploitation.

Composant Rôle Exemples
CPU Exécute les instructions machine (calculs, branchements). Intel i7, Ryzen, ARM, Apple M2.
RAM Mémoire temporaire des programmes en cours. 8 Go DDR4, 16 Go DDR5.
Stockage Conservation durable des fichiers et programmes. SSD, HDD, clé USB.
Carte mère & bus Relient les composants et transportent les données. PCIe, bus mémoire, USB.
Périphériques Entrée/sortie avec l’utilisateur ou le réseau. Écran, clavier, souris, carte réseau.
OS Gère ressources matérielles, fichiers, processus, droits. Linux, Windows, macOS, Android.

📋 Fiche synthèse interactive

  • OS, c’est quoi ? Chef d’orchestre logiciel : lance les applis, partage CPU/RAM, gère fichiers/permissions et périphériques.
  • RAM quand on éteint ? Mémoire volatile : tout est perdu si ce n’est pas écrit sur le disque.
  • Rôle du bus ? Réseau interne qui transporte bits et octets entre CPU, RAM, stockage et périphériques.
  • Multitâche ? L’OS partage le temps CPU entre plusieurs programmes ; chacun croit être seul.
  • Plusieurs OS sur un PC ? Oui via multi‑boot ou virtualisation (machines virtuelles).

🌍 Applications concrètes

  • PC, serveurs, smartphones, consoles, objets connectés partagent la même logique CPU + RAM + stockage + OS.
  • Raspberry Pi : excellent support pour tester Linux, serveurs, scripts de sécurité.
  • Virtualisation : lancer plusieurs OS sur la même machine pour tester, sécuriser, isoler.

❌ Erreurs fréquentes

  • Confondre RAM et disque (stockage permanent).
  • Penser que l’OS “fait tout” au lieu d’orchestrer le matériel.
  • Croire qu’ajouter de la RAM suffit toujours à accélérer une machine.
