📚 Cours complet – Données en tables

Une table organise des données en lignes (enregistrements) et colonnes (attributs).

ExempleColonnesLignesUtilisation
Contacts Nom, Prénom, Téléphone Une personne Recherche rapide, tri alphabétique.
Notes Élève, Matière, Note Un contrôle Moyennes, classements, filtres.
Ventes Produit, Date, Prix Un achat Statistiques de chiffre d’affaires.
  • Représentation Python typique : liste de listes, ex de>table = [["Alice",17],["Bob",16]].
  • Opérations clés : création, recherche, tri, filtre, statistiques, suppression/ajout de lignes.

📋 Fiche synthèse interactive

  • Accès à la 2ᵉ colonne ? Avec l’indice 1 : de>ligne[1] (indices commencent à 0).
  • Trier par colonne en Python ? de>sorted(table, key=lambda l: l[1]) pour trier selon la colonne d’indice 1.
  • Supprimer une ligne ? de>del table[i] ou requête de>DELETE en SQL.
  • Moyenne d’une colonne de notes ? Extraire la colonne, puis de>moy = sum(notes)/len(notes).
  • Recherche d’une valeur ? de>for ligne in table: if ligne[2] == valeur: ...

🌍 Applications concrètes

  • Notes, bulletins, fiches patients, inventaires, logs.
  • Excel, Google Sheets, bases de données SQL.
  • Traitement de CSV, scripts d’analyse en Python.

❌ Erreurs fréquentes

  • Oublier que les indices commencent à 0.
  • Confondre ligne (enregistrement) et colonne (attribut).
  • Faire une moyenne sans filtrer les lignes concernées.

📚 Lexique express

Table, ligne, colonne, enregistrement, attribut, CSV, filtre, tri, clé primaire.
Le format CSV, très simple, est utilisé partout pour échanger des tables entre logiciels différents.
