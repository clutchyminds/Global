📚 Cours complet – Traitement des données en tables

Une table est une collection structurée de données disposées en lignes et colonnes. On retrouve cette organisation dans les tableurs (Excel), bases de données, grilles de jeux, carnets, bulletins scolaires…

ExempleColonnesLignesUtilisation
Table de contacts Nom, Prénom, Téléphone Chaque personne Recherche rapide, rangement ordonné
Table de notes Élève, Matière, Note Chaque contrôle Calculs statistiques, tri, affichage synthèse
Table des ventes Produit, Date, Prix Chaque achat Bilan chiffre d’affaires, tri, recherches ciblées

Principales opérations :
- Création et remplissage d’une table.
- Recherche d’informations (filtre sur une colonne, sur une valeur…)
- Tri (par ordre alphabétique, croissant, etc.)
- Calculs statistiques (moyenne, somme, max, min…)
- Modification ou suppression de lignes ou colonnes.

  • En Python on utilise souvent la structure listes de listes :
    table = [[nom, age], [“Alice”,17], [“Bob”,16]]
  • En base de données (SQL), une table structure les enregistrements par colonnes.
  • Avec les tableaux NumPy en NSI spécialité, on peut gérer de grands volumes et faire des calculs rapides.

Ex : Pour chercher tous les élèves ayant plus de 17 ans : on parcours les lignes et on teste la valeur de la colonne “âge”.

📋 Fiche synthèse interactive

  • Comment accéder à la 2e colonne d’une table ? Par l’indice 1 : ligne[1] (indices commencent à 0 !)
  • Comment trier une table selon une colonne ? Utilise la fonction sorted() en Python avec clé : sorted(table, key=lambda l:l[1])
  • Peut-on supprimer une ligne dans une table ? Oui, avec del table[i] ou une fonction “delete” en SQL !
  • Défi : Pour calculer la moyenne de la colonne “Note” d’une table, que faire ? Parcourir toute la colonne, additionner, puis diviser par le nombre de lignes :
    moyenne = sum(notes)/len(notes)
  • Comment chercher une valeur précise dans une colonne ? On teste chaque ligne : for ligne in table: if ligne[2]==valeur: ...

💡 Exercices interactifs

Dans la table [["Alice",15],["Bob",17],["Cara",17]], quelle commande donne tous les âges ?

[ligne[1] for ligne in table] — on parcourt la colonne {âge}.

Sur la même table, comment afficher les noms de ceux qui ont 17 ans ?

[ligne[0] for ligne in table if ligne[1]==17]

🌍 Applications concrètes

  • Notes, bulletins scolaires, fiche de patients, inventaire d’entreprise, grille de Sudoku...
  • Tableaux Excel, Google Sheets, base de données SQL
  • Import/export de données (CSV, TXT), calculs, tris, statistiques

❌ Erreurs fréquentes à éviter

  • Oublier que les indices commencent à 0 en Python
  • Confondre ligne et colonne (ligne = personne entière, colonne = même info pour tous)
  • Ne pas filtrer une table avant de faire moyenne ou somme
  • Renommer ou supprimer sans faire attention à l’ordre des colonnes
  • Oublier le format CSV pour importer/exporter

📚 Lexique express

Table : grille de données (lignes/colonnes)
Colonne : attribut (ex : nom, âge, note)
Ligne : enregistrement (ex : un élève)
CSV : texte structuré où chaque ligne est une entrée de table ; séparateur = “,”
Filtrer : ne conserver que certains résultats (condition)
Tri : réorganiser selon l’ordre voulu

📖 Anecdotes et histoire

  • Le format CSV (Comma Separated Values) existe depuis 1972 : universel, il est lu par la plupart des logiciels !
  • Les bases de données structurées “relationnelles” s’appuient sur des tables dont chaque colonne porte un nom (clé primaire, étrangère…)
  • Derrière Google Sheets ou Excel, ce sont des lignes et colonnes qui organisent TOUT.
Source : NSI, informatique pratique
