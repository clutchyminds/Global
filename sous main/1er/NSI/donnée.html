📚 Cours complet – Représentation des données en NSI

L’ordinateur manipule des valeurs selon leur type, pour savoir comment les stocker, calculer ou comparer :

Type Exemples Codage Particularité
Entier
(int)		 7, -42, 2025 Binaire (base 2)
Ex : 13 → 1101		 Valeurs sans virgule, positives ou négatives
Réel
(float)		 1.5, -0.01, 3.14 Binaire (norme IEEE754)
Arrondi possible		 À virgule (décimale ou scientifique)
Booléen
(bool)		 True (Vrai), False (Faux) 0 ou 1 (1 bit ou 1 octet) Deux valeurs pour une logique
Caractère
(char)		 'A', '!', '5' ASCII (7 bits), Unicode (8/16/32 bits) 1 symbole (lettre, chiffre, ponctuation…)

En mémoire, tout est transformé en binaire — chaque type a sa façon d’être codé :
- Entier : nombre, ex 25 en binaire = 11001
- Réel : nombre flottant, arrondi possible (ex : 0.1 n’est pas exactement stocké)
- Booléen : True/False → 1 ou 0
- Caractère : chaque lettre a son code, ex : “A” = 65 en ASCII (= 01000001 en binaire)

Attention : Un chiffre et un caractère n’ont pas le même codage : "1" (ASCII 49) ≠ 1 (entier binaire 00000001)
Les conversions et le choix du type sont essentiels pour éviter les bugs !

  • Un entier sur n bits : valeurs de -2n-1 à 2n-1-1 (ordinateur = limite de mémoire)
  • Un octet : 8 bits = 256 combinaisons possibles

En NSI, savoir représenter, convertir et reconnaître le bon type est indispensable pour tous les chapitres (algos, programmation, sécurité).

📋 Fiche synthèse interactive

  • Qu’est-ce qu’un type de donnée ? Catégorie définissant la nature d’une valeur : nombre, texte, logique. L’ordinateur ne les manipule pas de la même façon !
  • Dans quel alphabet sont codés les caractères ? ASCII pour les premiers ordinateurs (127 symboles), Unicode aujourd’hui (plus de 140 000 caractères !)
  • À quoi sert le booléen en NSI ? À représenter des situations vraies/faux. Exemples : “est-majeur ?” ou “mot de passe valide ?”
  • Défi : Combien de valeurs représente 4 bits ? 16 valeurs différentes (de 0000 à 1111 en binaire).

🌍 Applications concrètes

  • Systèmes numériques : Calculatrices, PC, téléphones codent tout en binaire, même les photos ou textes !
  • Stockage : Disques durs, clés USB : tout repose sur le codage des valeurs de base.
  • Programmation : Les types et conversions sont essentiels pour éviter des bugs (ex : division entière vs flottante).

❌ Erreurs fréquentes à éviter

  • Confondre le chiffre “1” (nombre) et le caractère “1” (texte).
  • Penser qu’un réel peut être représenté exactement comme une fraction mathématique (il y a un arrondi, ex : 0,1).
  • Oublier que binaire ≠ décimal : 10 en binaire = 2 en base 10.
  • Croire que tous les caractères ASCII sont affichables (32 premiers codes = caractères de contrôle !).

📚 Lexique express

Entier : nombre sans virgule (ex : 5, -42, 2025)
Réel : nombre à virgule, flottant (ex : 3.14, -0.01)
Booléen : valeur logique (True/Vrai ou False/Faux)
Caractère : symbole unique du texte (ex : 'A', '?', '4')
Bit : plus petite unité d’information binaire (0 ou 1)
Octet : groupe de 8 bits (256 valeurs différentes)

💡 Méthodologie clé pour le contrôle

  • Reconnais à chaque fois le bon type pour chaque valeur (ex : âge = entier, prix = réel, saisie ‘O/N’ = caractère ou booléen).
  • Sache représenter un nombre ou caractère en binaire et donner la plage de valeurs pour n bits.
  • Justifie pourquoi le choix du type est important (ex : éviter les bugs d’arrondi ou d’affichage).
  • Sois capable d’expliquer comment une info “de la vraie vie” devient une valeur binaire en mémoire.
  • Apprends et vérifie la table ASCII des caractères classiques.
  • Fais attention à la différence entre texte et nombre dans un programme !
