📄 À quoi sert le HTML ?

  • HTML signifie HyperText Markup Language, c’est le langage de base qui structure toute page web.
  • Il permet d’organiser le contenu en titres, paragraphes, images, listes, liens, tableaux… bref tout ce que tu vois sur un site web.
  • Un navigateur web lit ce code HTML pour afficher la page visuellement.
  • Le HTML ne gère pas le style ou le comportement (pour ça il y a le CSS et JavaScript), mais uniquement la structure et le sens du contenu.

Le HTML fonctionne avec des balises qui ouvrent et ferment des parties du contenu, comme par exemple :

<h1>Titre principal</h1>
<p>Un paragraphe de texte ici.</p>

Les balises indiquent ce que ce texte représente, ici un titre puis un paragraphe.

🧱 Structure de base d’un document HTML

Toute page HTML commence par une structure commune, obligatoire pour être valide et bien comprise par les navigateurs :

<!DOCTYPE html>
<html lang="fr">
  <head>
    <meta charset="UTF-8">
    <title>Titre de la page</title>
  </head>
  <body>
    Contenu visible ici
  </body>
</html>
  • <!DOCTYPE html> : déclaration du type de document (HTML5 ici).
  • <html lang="fr"> : racine du document, avec l’attribut lang précisant la langue.
  • <head> : zone pour les métadonnées (titre, encodage, liens vers CSS, scripts).
  • <body> : zone visible contenant tout ce qui s’affiche sur la page.

Cette structure est essentielle : le navigateur s’appuie dessus pour interpréter correctement ta page, afficher le titre dans l’onglet, connaitre la langue pour le référencement, etc.

🔖 Les balises HTML essentielles

Voici quelques balises de base à connaitre pour bien commencer :

  • <h1>...</h1> à <h6>...</h6> : titres de niveaux 1 à 6.
  • <p>...</p> : paragraphe de texte.
  • <a href="url">...</a> : lien cliquable vers une autre page ou ressource.
  • <img src="URL" alt="description"> : image (sans balise de fermeture), alt décrit l’image si elle ne charge pas.
  • <ul> / <ol> : listes à puces (ul) ou numérotées (ol), avec <li> pour chaque élément.
  • <div> : conteneur générique pour grouper des éléments, utile pour la mise en page.
  • <span> : comme div, mais pour du contenu inline (texte).

🖼️ Attributs et leurs rôles

Les balises peuvent contenir des attributs pour préciser ou modifier leur comportement :

  • href dans <a> : adresse du lien.
  • src dans <img> : source de l’image.
  • alt dans <img> : texte alternatif pour accessibilité et SEO.
  • id et class pour identifier ou classifier un élément, utiles pour le style CSS et le script.
  • title ajoute un tooltip au survol d’un élément.

Les attributs sont toujours placés dans la balise d’ouverture et s’écrivent sous la forme nom="valeur". Ils personnalisent le comportement ou l’apparence.

🧩 La sémantique HTML expliquée

Utiliser les bonnes balises selon le contenu, c’est la sémantique. Cela aide les navigateurs, moteurs de recherche, et aides techniques à mieux comprendre la page.

  • <header> : en-tête de page ou section.
  • <nav> : zone de navigation.
  • <main> : contenu principal unique de la page.
  • <section> : section thématique.
  • <article> : contenu indépendant (article, billet de blog).
  • <footer> : pied de page de section ou document.

Respecter la sémantique facilite aussi le travail du CSS et améliore l’accessibilité web (lecteurs d’écran...).

🔗 Liens, images et médias

Les liens et images sont les briques pour rendre une page riche et connectée :

<a href="https://exemple.com">Visitez notre site</a>
<img src="chat.jpg" alt="Photo d'un chat mignon">
  • Le href du lien indique l’adresse ciblée.
  • Le alt de l’image est indispensable pour l’accessibilité.
  • Les balises <video> et <audio> permettent d’intégrer facilement des médias multimédia.
  • Pour un lien ouvrant dans un nouvel onglet, ajoute target="_blank" à la balise <a>.

📝 Formulaires HTML : interagir avec l’utilisateur

Les formulaires recueillent des données : textes, choix, boutons, fichiers...

<form action="/envoyer" method="post">
  <label for="nom">Votre nom:</label>
  <input type="text" id="nom" name="nom">
  <input type="submit" value="Envoyer">
</form>
  • <form> regroupe des champs envoyés au serveur.
  • action : URL du serveur qui traite les données.
  • method : type de requête HTTP (GET ou POST).
  • Champs classiques : input (texte, bouton, fichier…), textarea, select (liste déroulante).
  • Les label améliorent l’accessibilité en désignant les champs.

💡 Exercices pratiques : créer ta première page HTML

Crée une page avec :

  1. Un titre principal.
  2. Un paragraphe de texte décrivant ton site.
  3. Une image avec description.
  4. Un lien vers un site que tu aimes.
<!DOCTYPE html>
<html lang="fr">
  <head>
    <meta charset="UTF-8">
    <title>Ma première page</title>
  </head>
  <body>
    <h1>Bienvenue sur mon site</h1>
    <p>Ceci est un paragraphe de présentation.</p>
    <img src="chaton.jpg" alt="Un chaton mignon">
    <a href="https://www.example.com">Visitez Example.com</a>
  </body>
</html>

🧠 Méthodologie & bonnes pratiques

  • Utilise toujours une indentation propre pour bien visualiser la structure.
  • Toujours déclarer la langue avec lang dans la balise html.
  • Ne pas oublier le <!DOCTYPE html> pour un rendu moderne.
  • Remplis toujours le alt des images pour l’accessibilité.
  • Teste ta page dans plusieurs navigateurs pour vérifier la compatibilité.

📚 Lexique HTML

Balise : élément structurant du HTML, en général pair avec une ouverture et une fermeture.
Attribut : information supplémentaire dans la balise d’ouverture.
Doctype : déclaration du type de document HTML.
Sémantique : usage approprié des balises selon le sens du contenu.
Élément inline vs block : différence d’affichage et de comportement des balises.
Anecdote : Le HTML a été inventé par Tim Berners-Lee en 1991 pour permettre de créer des pages web riches et accessibles via le navigateur web Mosaic, le premier navigateur graphique au monde.
