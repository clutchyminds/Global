Masterclass HTML — Le cours détaillé & interactif

Comprends tout sur HTML : structure, balises, attributs, liens, images, formulaires, sémantique et bonnes pratiques.

📄 À quoi sert le HTML ?

  • HTML (HyperText Markup Language) structure le contenu des pages web.
  • Il définit titres, paragraphes, listes, images, tableaux, liens, etc.
  • Le navigateur lit le HTML pour construire la page affichée à l’écran.
  • HTML décrit la structure et le sens, pas le style (CSS) ni le comportement (JavaScript).

HTML utilise des balises ouvrantes/fermantes :

de><h1>Titre principal</h1>
<p>Un paragraphe de texte ici.</p>

🧱 Structure de base d’un document HTML

Une page HTML valide suit toujours le même squelette :

de><!DOCTYPE html>
<html lang="fr">
  <head>
    <meta charset="UTF-8">
    <title>Titre de la page</title>
  </head>
  <body>
    Contenu visible ici
  </body>
</html>
  • de><!DOCTYPE html> : indique HTML5.
  • de><html lang="fr"> : racine du document et langue.
  • de><head> : métadonnées (titre, encodage, CSS...).
  • de><body> : tout ce qui est visible pour l’utilisateur.

🔖 Balises HTML essentielles

  • de><h1>...</h1> à de><h6>...</h6> : titres hiérarchisés.
  • de><p>...</p> : paragraphe.
  • de><a href="url">...</a> : lien.
  • de><img src="URL" alt="description"> : image.
  • de><ul>/de><ol> + de><li> : listes.
  • de><div> : bloc générique.
  • de><span> : conteneur en ligne pour du texte.

🖼️ Attributs et rôles

  • de>href : cible du lien dans de><a>.
  • de>src : source d’une image ou d’un média.
  • de>alt : texte alternatif d’une image.
  • de>id / de>class : identifiant ou catégorie, utiles pour CSS/JS.
  • de>title : info-bulle au survol.

Les attributs se placent dans la balise d’ouverture : de><tag attribut="valeur">.

🧩 Sémantique HTML

  • de><header> : en-tête de page ou de section.
  • de><nav> : navigation principale.
  • de><main> : contenu principal unique.
  • de><section> : bloc thématique.
  • de><article> : contenu autonome.
  • de><footer> : pied de page.

Une bonne sémantique améliore le SEO, l’accessibilité et la lisibilité du code.

🔗 Liens, images et médias

de><a href="https://exemple.com">Visitez notre site</a>
<img src="chat.jpg" alt="Photo d'un chat mignon">
  • de>target="_blank" ouvre un lien dans un nouvel onglet.
  • de><video>, de><audio> intègrent des médias.

📝 Formulaires HTML

de><form action="/envoyer" method="post">
  <label for="nom">Votre nom:</label>
  <input type="text" id="nom" name="nom">
  <input type="submit" value="Envoyer">
</form>
  • de><form> : conteneur des champs.
  • de>action : URL du traitement.
  • de>method : GET ou POST.
  • Champs : de>input, de>textarea, de>select, etc.

💡 Exercice pratique : première page

Créer une page avec un titre, un paragraphe, une image et un lien.

de><!DOCTYPE html>
<html lang="fr">
  <head>
    <meta charset="UTF-8">
    <title>Ma première page</title>
  </head>
  <body>
    <h1>Bienvenue sur mon site</h1>
    <p>Ceci est un paragraphe de présentation.</p>
    <img src="chaton.jpg" alt="Un chaton mignon">
    <a href="https://www.example.com">Visitez Example.com</a>
  </body>
</html>

🧠 Méthodologie & bonnes pratiques

  • Indenter correctement le code.
  • Mettre de>lang sur la balise de>html.
  • Utiliser systématiquement un de>alt pertinent sur les images.
  • Tester la page dans plusieurs navigateurs.

📚 Lexique HTML

Balise : élément structurant (souvent ouvrant/fermant).
Attribut : information additionnelle sur un élément.
Doctype : type de document (ex : HTML5).
Sémantique : choix de balises selon le sens du contenu.
Block / inline : éléments de bloc ou en ligne.
Anecdote : Tim Berners‑Lee invente HTML au début des années 1990 au CERN pour partager facilement des documents entre chercheurs.
