Masterclass NSI : Langages et programmation

Variables, instructions, boucles, fonctions, listes, fichiers… tout pour poser des bases solides de code.

📚 Cours complet — Initiation

Un langage de programmation sert à décrire un algorithme que la machine exécute.

Concept Explication Exemple Python
Variable Nom qui stocke une valeur. de>a = 5 ; de>nom = "Alice"
Contrôle Choix et répétitions. de>if a > 0: ; de>for i in range(5):
Fonction Bloc réutilisable. de>def salut(): print("Hello")
Liste Groupe de valeurs. de>notes = [12, 16, 10]
Fichier Persistance des données. de>open("data.txt")

📋 Fiche synthèse interactive

  • Boucle de 1 à 10 ? de>for i in range(1, 11): ...
  • Rôle d’une fonction ? Regrouper du code réutilisable, plus lisible et plus facile à tester.
  • Liste vs tableau ? En Python, liste = tableau dynamique ; dans d’autres langages, tableaux ont souvent taille fixe.
  • À quoi sert if ? Tester une condition et exécuter un bloc seulement si elle est vraie.
  • Lire un fichier ligne par ligne ? de>with open("monfichier.txt") as f: puis de>for line in f:.

❌ Erreurs fréquentes

  • Oublier l’indentation sous if/for/while en Python.
  • Utiliser de>= au lieu de de>== dans les conditions.
  • Lire un fichier sans le fermer (sauf avec de>with).

📚 Lexique express

Variable, boucle, condition (if), fonction, liste/tableau, fichier, paramètre, retour.
Python est pensé pour être lisible avant tout : l’indentation obligatoire évite beaucoup d’“usine à gaz” dans le code.
