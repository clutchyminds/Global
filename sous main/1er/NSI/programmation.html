📚 Cours complet — Initiation à la programmation

Un langage de programmation permet de donner des instructions à l’ordinateur, qui exécutera les calculs, actions, affichages demandés. Les langages peuvent être impératifs (Python, C, JavaScript…), logiques, fonctionnels… Ici, on commence par les bases.

Concept Explication Exemple Python
Variable Contient une valeur (nombre, texte, etc.) a = 5, nom = "Alice"
Structure de contrôle Oriente les actions : si/si…sinon, boucle if a > 0: ...
for i in range(5): ...
Fonction Regroupe des instructions réutilisables def salut(): print("Hello")
Tableau/Liste Groupe de valeurs numérotées notes = [12, 16, 10]
Fichier Stocke infos à relire (texte, CSV…) open("data.txt")
Principales étapes pour coder :
  • Déclarer et initialiser les variables
  • Utiliser structures de contrôle pour tester, répéter des actions (if, for, while)
  • Créer des fonctions pour organiser le code, éviter de répéter
  • Lire, modifier, parcourir tableaux/listes pour traiter plusieurs données
  • Lire/écrire des fichiers pour sauvegarder et réutiliser informations/paramètres

Exemple (Python) — Programme qui affiche la moyenne d’une liste de notes :
notes = [15, 12, 18]
def moyenne(liste):
  return sum(liste)/len(liste)
print(moyenne(notes))

Gestion de fichier — Lire chaque ligne d’un fichier texte :
with open("notes.txt") as f:
  for ligne in f:
    print(ligne)

Organisation du code et bonnes pratiques :

  • Bien nommer les variables
  • Commenter le code (“pourquoi” et “comment”)
  • Tester sur différentes valeurs
  • Faire des fonctions courtes, claires
  • Respecter l’indentation et la syntaxe

📋 Fiche synthèse interactive

  • Comment créer une boucle de 1 à 10 en Python ? for i in range(1, 11): ...
  • À quoi servent les fonctions en programmation ? À faire des blocs de code réutilisables, organisés, plus clairs à débugger.
  • Différence entre tableau et liste ? En Python, liste = tableau dynamique ; ailleurs, tableau est taille fixe.
  • À quoi sert l’instruction “if” ? À exécuter une action selon la condition (si vrai, alors…)

🌍 Applications concrètes

  • Statistiques, analyse de texte, gestion de listes, automatisation de tâches
  • Jeux vidéo (boucles, variables score et vie…), IA, robots, applis web
  • Outils pour traiter des fichiers CSV, logs, images, etc.
  • Systèmes embarqués : scripts pour Raspberry Pi, Arduino, etc.

❌ Erreurs fréquentes à éviter

  • Oublier l’indentation : Python en a besoin pour comprendre qui dépend de quoi
  • Utiliser = au lieu de == dans les tests
  • Parcourir une liste sans faire attention à la taille
  • Ne pas fermer les fichiers après lecture/écriture (sauf “with open…”)
  • Confondre le rôle des fonctions (fonctions ≠ boucles ≠ variables)

📚 Lexique express

Variable : nom qui contient une valeur
Boucle : “for”, “while”, pour répéter
If/Sinon : test/la condition
Fonction : bloc de code réutilisable
Tableau/Liste : plusieurs valeurs ensemble
Fichier : texte/binaire sauvegardé

📖 Anecdotes et histoire

  • Le langage Python, créé en 1991 par Guido van Rossum, est utilisé du collège à la NASA !
  • Les premiers langages (Fortran, C…) étaient écrits pour calculer et piloter des machines scientifiques.
  • L’indentation obligatoire de Python évite les erreurs de lecture (“pyramide de code” plus claire !)
  • “def” vient de “define”, “for” veut dire “pour chaque”, “if” veut dire “si...”
Source : Histoire des langages et de la programmation, NSI
Astuce mémoire : “Boucle for” = “pour” tous les éléments ; “def” pour “définir”, “if” pour “si”. Fais des fonctions courtes, c’est plus facile à relire !

💡 Méthodologie contrôle

  • Bien nommer, initialiser et commenter les variables
  • Utiliser boucles et structures pour traiter tous les cas possibles
  • Créer des fonctions pour organiser les programmes et montrer que tu sais structurer
  • Parcourir et modifier tableaux, fichiers, structures complexes
  • Gérer les erreurs (try/except, vérification des valeurs, tests de fichiers)
  • Justifier chaque choix et tester chaque partie sur des exemples simples et des cas limites !
