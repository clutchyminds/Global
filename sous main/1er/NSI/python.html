🐍 Qu’est-ce que Python ?

  • Langage interprété, multi‑plateforme et très lisible, idéal pour apprendre comme pour des projets pro.

🔠 Syntaxe et variables

  • Variables créées par simple affectation : pas de type à déclarer.
  • Types de base : de>int, de>float, de>str, de>bool.
  • Typage dynamique et fort : on peut changer la valeur, mais les opérations entre types incompatibles lèvent des erreurs.
de>age = 30

📦 Modules et POO

de>class Personne:
    def __init__(self, nom, age):
        self.nom = nom
        self.age = age

    def saluer(self):
        print(f"Bonjour, je suis {self.nom}.")

p = Personne("Alice", 30)
p.saluer()

💡 Exercices pratiques

1. Fonction de>factorielle(n) récursive.

2. Dictionnaire étudiant (nom, âge, notes) et moyenne.

de>def factorielle(n):
    if n <= 1:
        return 1
    return n * factorielle(n-1)

etudiant = {"nom": "Alice", "age": 22, "notes": [12, 14, 16]}
moyenne = sum(etudiant["notes"]) / len(etudiant["notes"])
print(f"Moyenne : {moyenne}")
print(factorielle(5))

🧠 Bonnes pratiques Python

  • Indentation de 4 espaces, jamais de tabulation mélangée.
  • Noms clairs, commentaires utiles, pas envahissants.
  • Tester chaque fonction avec plusieurs cas.
  • Découper en modules, réutiliser plutôt que copier‑coller.
