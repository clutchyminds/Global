🐍 Qu’est-ce que Python ?

  • Python est un langage de programmation interprété et multiplateforme, réputé pour sa syntaxe claire et sa facilité d’apprentissage.
  • Utilisé en science des données, web, automatisation, intelligence artificielle, jeux vidéo, applications robustes.
  • Créé en 1991 par Guido van Rossum, il repose sur la lisibilité du code pour faciliter la collaboration et la maintenance.
  • Sa large communauté et ses bibliothèques riches en font un langage versatile et puissant.

Son design s’inspire du langage ABC et met l’accent sur une syntaxe minimaliste où l'indentation remplace les accolades, pour structurer le code visuellement.

🔠 Syntaxe et variables en Python

Les variables en Python n'ont pas besoin d'être déclarées explicitement : elles sont créées dès la première assignation.

  • Les types principaux sont int, float, str, bool.
  • Python est fortement typé : une variable garde son type, mais le typage est dynamique.
  • La convention est d’utiliser le snake_case pour nommer variables et fonctions.
  • Tu peux assigner plusieurs variables en une ligne, et échanger facilement les valeurs : a, b = b, a
age = 30
nom = "Alice"
taille = 1.75
est_actif = True
a, b = 5, 10
a, b = b, a  # échange

Le typage dynamique permet de reassigner une variable avec un type différent, mais cela peut aussi être source d’erreurs si mal géré.

⚖️ Types de données et opérations

Les types de base permettent de faire des opérations mathématiques, des manipulations de chaînes et des comparaisons.

  • Opérateurs mathématiques : +, -, *, /, // (division entière), % (modulo), ** (puissance).
  • Opérateurs de comparaison : ==, !=, <, >, <=, >=.
  • Concaténation de chaînes : avec +, ou avec f-string pour l’interpolation.
x = 10 + 4 * 2
y = 15 // 4  # 3
z = 5 % 2   # 1
nom = "Alice"
message = f"Bonjour {nom} !"
print(message)

🔀 Structures de contrôle : conditions et boucles

Le contrôle de flux est essentiel pour prendre des décisions et répéter des actions.

  • if / elif / else : blocs conditionnels indentés pour exécuter le code selon des tests booléens.
  • while : boucle tant que la condition est vraie.
  • for : boucle sur une séquence (liste, chaîne, range...).
  • break / continue : permettent d’arrêter ou sauter une itération dans une boucle.
age = 20
if age >= 18:
    print("Majeur")
elif age >= 13:
    print("Adolescent")
else:
    print("Enfant")

for i in range(5):
    if i == 3:
        continue
    print(i)

🧩 Fonctions : bloquer et réutiliser un code

Une fonction contient un groupe d’instructions réutilisables, avec des paramètres et éventuellement une valeur retournée.

  • Déclaration avec def nom_fonction(param1, param2):.
  • Utilisation du mot-clé return pour renvoyer une valeur.
  • Les fonctions peuvent avoir des arguments par défaut, des paramètres nommés, et accepter un nombre variable d’arguments.
def saluer(nom="ami"):
    return f"Bonjour {nom} !"

print(saluer())
print(saluer("Alice"))

📚 Listes, tuples, dictionnaires et ensembles

Python offre plusieurs structures pour stocker des collections de données.

  • Liste : mutable, ordonnée, modifiable (ex : [1, 2, 3]).
  • Tuple : immuable, ordonné, plus sécurisé (ex : (1, 2, 3)).
  • Dictionnaire : collection clé-valeur avec clés uniques (ex : {"nom":"Alice", "age":30}).
  • Set : collection non ordonnée d’éléments uniques.
liste = [1, 2, 3, 4]
tuple_ = (10, 20, 30)
dico = {"nom": "Alice", "age": 25}
ensemble = {1, 2, 3, 4}

🛠️ Gestion d’erreurs et exceptions

Pour gérer les erreurs sans faire planter le programme, Python utilise les exceptions.

  • try / except : tenter un bloc de code, intercepter les erreurs.
  • else : exécuter si pas d’erreur.
  • finally : code toujours exécuté, pour nettoyage.
  • On peut lever des erreurs personnalisées avec raise.
try:
    x = int(input("Entrez un nombre : "))
except ValueError:
    print("Ce n'est pas un nombre valide.")
else:
    print("Merci !")
finally:
    print("Fin du programme.")

📁 Lecture et écriture de fichiers

Python facilite la manipulation de fichiers texte ou binaire pour sauvegarder ou lire des données.

  • Ouvrir un fichier avec open("fichier.txt", "r") (mode lecture) ou "w" (mode écriture).
  • Utiliser with pour gérer correctement la fermeture automatique.
  • Lire tout le contenu avec read(), lire ligne à ligne avec readline() ou readlines().
  • Écrire du texte avec write().
with open("data.txt", "w") as f:
    f.write("Hello World\n")

with open("data.txt", "r") as f:
    contenu = f.read()
    print(contenu)

📦 Modules et packages

Pour organiser et réutiliser le code, on divise souvent en modules et packages.

  • Module : un fichier Python (.py) contenant des fonctions, classes, variables.
  • Importer avec import nom_module ou from nom_module import fonction.
  • Package : dossier contenant plusieurs modules et un fichier __init__.py.
  • Utiliser pip pour installer des packages externes (ex : numpy, pandas).

🔄 Programmation orientée objet (POO)

La POO permet de modéliser des objets avec attributs (données) et méthodes (fonctions associées).

  • Définir une classe avec class NomClasse :.
  • Créer des objets (instances) en appelant la classe.
  • Surcharge du constructeur __init__ pour initialiser les objets.
  • Héritage, encapsulation et polymorphisme pour structurer des programmes complexes.
class Personne:
    def __init__(self, nom, age):
        self.nom = nom
        self.age = age

    def saluer(self):
        print(f"Bonjour, je suis {self.nom}.")

p = Personne("Alice", 30)
p.saluer()

💡 Exercices pratiques

1. Écris une fonction facteurielle(n) qui calcule la factorielle récursivement.

2. Crée un dictionnaire représentant un étudiant (nom, âge, notes) et affiche la moyenne.

def factorielle(n):
    if n <= 1:
        return 1
    else:
        return n * factorielle(n-1)

etudiant = {
    "nom": "Alice",
    "age": 22,
    "notes": [12, 14, 16]
}

moyenne = sum(etudiant["notes"]) / len(etudiant["notes"])
print(f"Moyenne : {moyenne}")

print(factorielle(5))
