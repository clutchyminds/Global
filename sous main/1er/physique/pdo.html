Propagation des ondes : mécaniques et électromagnétiques

Cours interactif sur les ondes : propagation, vitesse, caractéristiques, schéma, QCM, exos, LaTeX, fiche, lexique, notes…

📚 Objectifs

  • Comprendre et modéliser la propagation d’une onde mécanique ou électromagnétique
  • Maîtriser les grandeurs : amplitude, célérité, fréquence, longueur d’onde, période
  • Savoir résoudre les exercices type : calcul vitesse, fréquence, interpréter un schéma

🌊 1. Onde mécanique

  • Déf. : perturbation qui se propage dans la matière (ex : corde, son, vague…)
  • Caractéristiques principales :
    • Amplitude : hauteur du signal
    • Fréquence (\( f \)), période (\( T \)), relation : \( f = 1/T \)
    • Célérité (\( v \)) : vitesse de propagation (\( v = \lambda \cdot f \))
    • Longueur d’onde (\( \lambda \ )) : distance parcourue par l’onde en une période
  • Lexique mécanique

💡 2. Onde électromagnétique

  • Déf. : onde qui se propage SANS support matériel (ex : lumière, radio, micro-ondes, rayons X…)
  • Caractéristiques :
    • Célérité fixe dans le vide : \( c = 3,00 \times 10^8~m/s \)
    • Longueur d’onde (\( \lambda \)), fréquence (\( f \ ))
    • Relation : \( c = \lambda \cdot f \)
  • Lexique électromagnétique
Schéma : onde mécanique (corde) + onde électromagnétique (lumière)

📑 Exercices interactifs

🔖 Fiche de révision rapide

  • Onde mécanique : nécessite un support (corde, eau, air…)
  • Onde électromagnétique : pas de support, vitesse = c
  • Relation vitesse-longueur-fréquence : \(v = \lambda \cdot f\), \(c = \lambda \cdot f\)
  • Fréquence = 1/période
  • Longueur d’onde = distance parcourue en 1 période

❌ Erreurs fréquentes à éviter

  • Confondre onde mécanique (son, corde) et électromagnétique (lumière)
  • Oublier unités (fréquence Hz, longueur d’onde m ou nm, période s)
  • Inverser formule vitesse/fréquence/longueur
  • Ne pas identifier le support de propagation
  • Mal lire la période sur le graphique

📚 Lexique express

  • Onde : perturbation qui se propage (transfert d’énergie, pas de matière)
  • Célérité : vitesse de propagation (mécanique : v, électromagnétique : c)
  • Amplitude : “hauteur” de l’onde
  • Fréquence (f) : nombre d’oscillations par seconde (Hz)
  • Période (T) : durée d’une oscillation (s)
  • Longueur d’onde (\(\lambda\)) : distance parcourue en une période (m)

Applications

Son (ondes mécaniques), radio, lumière, IR, micro-ondes, rayons X (ondes électromagnétiques), séismes, télécommunications…

Lexique mécanique

Onde transverse/longitudinale, amplitude, fréquence, période, vitesse. Ex : corde, ressort, son.

Lexique électromagnétique

Spectre : radio, micro-ondes, IR, visible, UV, X, gamma. Célérité = c dans le vide.
