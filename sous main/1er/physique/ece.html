pH, acides/bases dans l’eau, couples oxydant/réducteur, QCM, exercices, LaTeX, fiches, lexique et astuces.

🌱 Pourquoi ce thème ?

  • Comprendre pH des eaux, pluies acides, traitement des eaux.
  • Saisir le rôle de l’oxydoréduction dans corrosion, dépollution, respiration.

🔬 1. Acidité, basicité & pH

  • pH mesure l’acidité : pH < 7 acide, pH = 7 neutre, pH > 7 basique.
  • Définition : \( \mathrm{pH} = -\log_{10} [\mathrm{H}^+] \) avec \([\mathrm{H}^+]\) en mol·L⁻¹.
  • Neutralisation : H⁺ + OH⁻ → H₂O.
Échelle de pH : acide → neutre → basique.
Le pH de certaines pluies urbaines peut descendre sous 5, signe de pollution acide.

🧪 2. Couples acide/base

  • Acide HA donne H⁺, base A⁻ le récupère : couple HA/A⁻.
  • Exemples : H₂O/OH⁻, HCO₃⁻/CO₃²⁻, NH₄⁺/NH₃.
  • Réaction générale : HA + H₂O ⇌ A⁻ + H₃O⁺.

⚡ 3. Oxydoréduction

  • Oxydant capte e⁻, réducteur cède e⁻.
  • Couple Ox/Red : Fe³⁺/Fe²⁺, Cl₂/Cl⁻, O₂/H₂O, MnO₄⁻/Mn²⁺…
  • Équation type : Ox + ne⁻ ⇌ Red.

🔖 Fiche de révision rapide

  • pH = −log₁₀[H⁺] ; [H⁺] = 10⁻ᵖᴴ.
  • Acide : donne H⁺ ; Base : capte H⁺ ou donne OH⁻.
  • Couple acide/base : HA/A⁻ ; couple redox : Ox/Red.
  • Oxydant gagne e⁻ ; Réducteur perd e⁻.

❌ Erreurs fréquentes

  • Donner une unité au pH (il n’en a pas).
  • Dire “oxydant = oxygène uniquement”.
  • Écrire une équation sans équilibrer charges et atomes.

🗒️ Tes propres notes

Sources : cours lycée, manuels, éduscol, chimie de l’environnement, BAC 2025.

Enjeux environnementaux

pH des fleuves, traitement des eaux, pluies acides (SO₂/NO₂), corrosion des métaux, oxydation dans l’atmosphère.

Calcul de pH

Pour [H⁺] = 1,0×10⁻⁵ mol·L⁻¹ : pH = −log(1×10⁻⁵) = 5 → solution acide.

Neutralisation

H⁺ + OH⁻ → H₂O (solution plus proche de la neutralité).

Couples acide/base

Exemples : HNO₃/NO₃⁻ ; H₂CO₃/HCO₃⁻ ; NH₄⁺/NH₃.

Exemple redox

Fe + 2H⁺ → Fe²⁺ + H₂. Fer s’oxyde (Fe → Fe²⁺), H⁺ se réduit (H⁺ → H₂).

Couples redox

Exemples : Cl₂/Cl⁻, O₂/H₂O, Fe³⁺/Fe²⁺, MnO₄⁻/Mn²⁺.
