Quantités de matière, mole, concentration, dilution

Quantité de matière, nombre de moles, concentration molaire et dilution avec exemples, QCM et exercices corrigés.[web:138][web:140][web:139][web:146][web:147]

📚 Introduction & objectifs

  • Calculer une quantité de matière à partir d’une masse ou d’une concentration.[web:138][web:140][web:146]
  • Exprimer correctement une concentration molaire et gérer une dilution.[web:139][web:146][web:145]

🎯 1. Définitions essentielles

  • Quantité de matière n : nombre de moles d’une espèce dans un échantillon (en mol).[web:138][web:140]
  • Une mole correspond à \(6{,}02×10^{23}\) entités (nombre d’Avogadro \(N_A\)).[web:138][web:140]
  • Masse molaire M : masse d’une mole d’espèce chimique (en g·mol⁻¹).[web:138][web:140][web:146]
  • Concentration molaire C : quantité de matière par litre de solution (mol·L⁻¹).[web:140][web:139][web:146]
  • Dilution : préparation d’une solution fille moins concentrée à partir d’une solution mère plus concentrée.[web:139][web:145]

💡 Formules fondamentales

  • Quantité de matière : \(n = \dfrac{m}{M}\) ou \(n = C·V\).[web:138][web:140][web:146]
  • Concentration molaire : \(C = \dfrac{n}{V}\).[web:140][web:146]
  • Dilution : \(C_1 V_1 = C_2 V_2\).[web:139][web:145]

🧪 2. Exemples de calculs

  • Masse molaire de NaCl : M(NaCl) = 23,0 + 35,5 = 58,5 g·mol⁻¹.[web:138][web:147]
  • Pour 20 g de glucose de masse molaire 180 g·mol⁻¹, n = 20/180 ≈ 0,11 mol.[web:138][web:140]
Dilution : solution mère concentrée → solution fille plus diluée.

🔍 3. Dilution : principe

  • Égalité des moles de soluté avant et après dilution : \(n_1 = n_2\), d’où \(C_1V_1 = C_2V_2\).[web:139][web:145]
  • Tous les volumes doivent être dans la même unité, souvent en L ou tous en mL.[web:139][web:146]

🔖 Fiche de révision rapide

  • \(n = \dfrac{m}{M}\) ou \(n = C·V\).[web:138][web:140][web:146]
  • \(C = \dfrac{n}{V}\) (V en L, C en mol·L⁻¹).[web:140][web:146]
  • Dilution : \(C_1V_1 = C_2V_2\).[web:139][web:145]
  • 1 mol = \(6{,}02×10^{23}\) entités (nombre d’Avogadro).[web:138][web:140]

❌ Erreurs fréquentes

  • Oublier d’exprimer V en L dans les formules avec C (mol·L⁻¹).[web:139][web:140][web:146][web:144]
  • Confondre masse m et masse molaire M (g vs g·mol⁻¹).[web:138][web:140][web:147]

Astuce Mole

La mole est un « paquet chimique » : comme une douzaine, mais contenant \(6{,}02×10^{23}\) entités.[web:138][web:140]

Calcul explicité

Pour 20 g de glucose (\(M=180\ g·mol^{-1}\)) : \(n = 20/180 ≈ 0,11\) mol.[web:138][web:140]

Exemple de dilution

Pour obtenir 100 mL à 0,020 mol·L⁻¹ à partir d’une solution à 0,10 mol·L⁻¹ : \(V_1 = C_2V_2/C_1 = (0,020×100)/0,10 = 20\) mL.[web:139][web:145]

Formules principales

n = m/M ; C = n/V ; C₁V₁ = C₂V₂ ; l’unité de C est mol·L⁻¹.[web:138][web:140][web:139][web:146]
