Description du mouvement : repérage, référentiel, trajectoire, vitesse

Repérage, référentiels, trajectoires, vitesses, QCM, exercices, schéma interactif, LaTeX, fiche, lexique et sauvegarde de notes.

📚 Objectifs

  • Décrire les mouvements à l’aide d’un référentiel adapté.
  • Relier repérage (x, y, z, t), trajectoire et vitesse.
  • Maîtriser vocabulaire et unités pour les contrôles.

📍 1. Repérage et référentiel

  • Position = coordonnées (x, y, z) à un instant t dans un référentiel donné.
  • Référentiel = “décor” + repère (origine, axes). Ex : terrestre, géocentrique, héliocentrique.

🗺️ 2. Trajectoire

  • Trajectoire : ensemble des positions successives du mobile.
  • Peut être rectiligne, circulaire, parabolique, elliptique, selon le système et le référentiel.

Exemples : trajectoires rectiligne, circulaire, parabolique.

🏃‍♂️ 3. Vitesse

  • Vitesse moyenne : \(v_{moy} = \dfrac{\Delta x}{\Delta t}\).
  • Vitesse instantanée en 1D : \(v(t) = \dfrac{dx}{dt}\).
  • Mouvement uniforme : vitesse constante ; accéléré : vitesse varie, \(a = dv/dt\).

🔖 Fiche de révision rapide

  • Repérage : (x, y, z, t) dans un référentiel.
  • Trajectoire : chemin suivi par le mobile.
  • Vitesse moyenne : \(\Delta x / \Delta t\).
  • Vitesse instantanée : dérivée de la position, dx/dt.

❌ Erreurs fréquentes

  • Parler de mouvement sans préciser le référentiel.
  • Confondre trajectoire (forme) et distance parcourue.
  • Mélanger vitesse moyenne et instantanée.

📚 Lexique express

Référentiel, position, trajectoire, vitesse, accélération, repère, origine.

🗒️ Tes propres notes

Sources : cours lycée, manuels, BAC 2025, fiches PC.

Applications concrètes

Voiture dans un virage, satellites, drones, chutes libres, sports (ballon, sprinteur), transports (train, avion).

Schéma trajectoire

Ligne droite = rectiligne, cercle = circulaire, parabole = projectile. Le référentiel change la forme observée.

Astuce vitesse

Toujours penser “variation” : \(\Delta x / \Delta t\) ou dérivée. Vérifier systématiquement l’unité (m/s).

Lexique repérage

Référentiel = origine + axes. Repérage = où et quand. Coordonnées = valeurs x, y, z dans ce repère.
